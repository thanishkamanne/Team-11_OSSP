Operating system concepts in this project

ConceptWhere it is used
Process states and /procEvery table reads live data from the kernel's /proc filesystem.
fork and execEach managed worker is created with fork+exec, then forks child processes to use CPU.
Inter-process communicationThe manager sends allocation commands to workers through a pipe.
SignalsStop, Continue and Kill send SIGSTOP, SIGCONT and SIGKILL to a worker's process group.
Scheduling priorityRenice calls setpriority() to change a worker's nice value.
Deadlock avoidanceBanker's algorithm decides whether a request leaves the system in a safe state.
